## Описание алгоритма: сортировка выбором (Selection Sort)

Рассмотрим процесс сортировки элементов массива `A` следующим образом:

1. Сначала находится наименьший элемент массива `A`, который ставится на место элемента `A[1]`.
2. Затем находится второй по величине наименьший элемент массива `A`, который ставится на место элемента `A[2]`.
3. Этот процесс продолжается для первых `n-1` элементов массива `A`.

### Задание

1. Запишите псевдокод данного алгоритма (сортировка выбором).
2. Какой инвариант цикла сохраняется в этом алгоритме?
3. Почему достаточно выполнить алгоритм только для первых `n-1` элементов, а не для всех `n`?
4. Определите время работы алгоритма в наилучшем и наихудшем случаях и запишите его в Θ-обозначениях.
